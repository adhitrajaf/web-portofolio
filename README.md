# Adhitya Fajar Rachmadi, S.T. — Portfolio Website

Modern, interactive Next.js portfolio built for Vercel deployment.

## Key Features
- **Default Dark Mode + Light Mode Toggle** (persisted via `localStorage`)
- **Dual-Role Split Experience Architecture**:
  - **Zurich Indonesia** — *IT & Business Analyst Team (Dedicated via PT Care Technologies)* (`Sept 2026 – Present`)
  - **PT Care Technologies** — *IT Programmer, Middleware Research & Development (R&D) Department* (`Sept 2026 – Present`)
- **Interactive Full-Logo Technology Stack**:
  - Includes C#, Visual Basic (VB.NET), PHP, Laravel, JavaScript, SQL Server Management Studio (SSMS), REST API, Postman, Python, C++, Docker, FastAPI, plus full AI/ML and Industrial Automation logos.
- **Interactive Multi-Slide Presentation Decks**:
  - *SmartAssist Agentic Chatbot & Executive Dashboard* (4 interactive slides)
  - *AI Stock Trading Systems* (5 interactive slides)
  - *Interactive Certificate Slider & Lightbox Modal*

## Easy Content Updates
All experience items, skills, case studies, and credentials are centralized in:
`src/data/portfolioData.ts`

## Local Development
```bash
npm install
npm run dev
```
